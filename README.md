# Fit Log

Fit Log is a modern fitness web application designed to help users explore workouts, save their favorite exercises, and organize their daily workout plans in one place.

## Technologies Used

* **Next.js** — React framework for application development
* **React** — Building reusable and interactive UI components
* **Tailwind CSS** — Responsive styling and modern UI design
* **Sonner** — Toast notifications and user feedback
* **Lucide React** — Clean and customizable icons

## Key Features

### 1. Workout Library

Browse a collection of workouts and explore different exercises based on your fitness needs.

### 2. Today's Workout Plan

View and manage the workouts planned for the current day, making it easier to stay consistent with your fitness routine.

### 3. Save Workouts

Save workouts that you are interested in and easily access them later.

### 4. Detailed Workout Pages

View detailed information about each workout, including workout instructions and relevant exercise information.

### 5. Notifications

Receive clear and interactive notifications to get feedback when performing actions within the application.
